Product Creation Control

A powerful user-level permission module that gives administrators full control over who can create products and from which location inside Odoo — per user, per source.

Odoo 18 Inventory Sales Purchase Manufacturing Free
Problem This Module Solves
⚠️

Standard Odoo has no product creation restriction

Any user can create a new product from multiple places — the Product menu, Sales Order lines, Purchase Order lines, Bills of Materials, Inventory adjustments, or the Vendor Pricelist. This causes:

  • Duplicate products created by untrained users
  • Incorrect product names, categories, or configurations
  • Dirty product master data that is extremely hard to clean
  • No accountability — anyone can create anything from anywhere
  • Inventory and reporting errors due to wrong product entries
Solution
✅

Per-user, per-source product creation permissions

This module lets the administrator assign granular permissions per user — controlling exactly which product creation sources they can use, and whether they can edit product names or categories.

  • Only authorized users can create products from specific sources
  • Unauthorized attempts are blocked with a clear, friendly error message
  • Superuser / Administrator is always unrestricted
  • If no permission record exists for a user — they are blocked by default (secure by design)

Permission Matrix

Creation Permissions — control where a user can create new products:

Source What It Controls
Product MenuCreate product directly from Inventory / Sales product list
Sales Order LineCreate product on-the-fly inside a Sales Order
Purchase Order LineCreate product on-the-fly inside a Purchase Order
Manufacturing BOMCreate product while building a Bill of Materials
Inventory OperationsCreate product during inventory adjustments
Vendor PricelistCreate product from supplier info / vendor pricelist

Edit Permissions — control what a user can modify on existing products:

Permission What It Controls
Change Product NameAllow or block renaming an existing product
Change Product CategoryAllow or block changing an existing product's category
Default behavior: If no permission record exists for a user, they are blocked from all product creation by default. Superuser and Administrator accounts always bypass all restrictions.
How It Works
1

Open Configuration

Go to Product Control → Configuration → User Permissions from the Odoo menu.

2

Create a Permission Record

Add a new entry and select the user you want to configure permissions for.

3

Toggle Permissions

Enable or disable each source permission and edit permission using the toggle switches.

4

Save & Apply

Save the record — restrictions apply immediately for that user. No restart required.

5

Blocked Users See a Clear Message

When a restricted user tries to create a product from a blocked source, Odoo shows a friendly error message guiding them to contact the administrator.
